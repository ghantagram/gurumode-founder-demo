# GuruMode founder demo

Compiled browser distribution for ten prepared learning experiences.

The four science experiments were created through the GuruMode ChatGPT pipeline. This hosted preview runs saved models in the visitor browser; live generation and account saving are not enabled. Independent teacher review is pending.

Render static-site settings:
- Build command: `node verify.mjs`
- Publish directory: `site`
- Branch: `main`

Only the browser distribution is included here.
